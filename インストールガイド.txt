=====================================================
 集中トラッカー インストールガイド
 (新しいPCへの導入・引っ越し)
=====================================================


-----------------------------------------------------
 0. アプリを手に入れる(GitHubから)
-----------------------------------------------------
 すでにフォルダをお持ちなら、この節は飛ばして「1.」へ。

 ▼かんたんな方法(ソフトの追加は不要)

   1. ブラウザで次を開きます
      https://github.com/m-higashi/focus-tracker
   2. ファイル一覧の右上にある緑色の「Code」ボタンを押します
   3. 出てきたメニューのいちばん下「Download ZIP」を押します
   4. ダウンロードされたZIPをダブルクリックして展開します
      (フォルダ名は何でも構いません)

 ▼gitを使う方法(更新を受け取りやすい)

   ターミナル(Mac)またはコマンドプロンプト(Windows)で:

     git clone https://github.com/m-higashi/focus-tracker.git

   更新するときは、そのフォルダの中で  git pull  を実行するだけです。
   記録したデータ(data フォルダの中)は更新の対象外なので消えません。

 ▼Windowsで Node.js を入れたくない場合

   GitHubページの「Releases」から Node同梱zip(-win-x64.zip)を
   ダウンロードすると、解凍して Start.bat を押すだけで動きます。


-----------------------------------------------------
 1. はじめて使うPCに入れる(所要10分) ＜Windows＞
-----------------------------------------------------
 ※Macをお使いの場合は「1-M. Macに入れる」へ

 手順1: このフォルダをPCの好きな場所に置く
   デスクトップでもドキュメントでもどこでもOKです。
   後から移動しても問題ありません。

 手順2: Setup.bat をダブルクリック
   Node.js(アプリの動作に必要な無料ソフト)が入っているか
   自動でチェックします。

   → 「[OK]」と出たら手順4へ
   → 「[NG]」と出たら、自動で開くダウンロードページから
     「LTS」と書かれた緑のボタンでインストーラーを入手し、
     設定は変えずに「次へ」を押していけば完了です。
     終わったらもう一度 Setup.bat を実行して[OK]を確認。

 手順3: (スマホからも使う場合)Tailscale を入れる
   PCとスマホの両方に Tailscale(無料)をインストールして
   同じアカウントでログインしてください。
   https://tailscale.com/download
   ※PCだけで使うなら不要です。

 手順4: Start.bat をダブルクリック
   黒い窓が開いてアプリが起動します。
   窓に表示されるアドレスをブラウザで開いてください。
   ・このPCなら ....... http://localhost:3000
   ・スマホからは ..... 窓に表示される http://100.x.x.x:3000

 手順5: (おすすめ)自動起動を登録する
   RegisterAutostart.cmd をダブルクリックすると、
   PCにサインインしたとき自動でアプリが起動するようになります。
   やめたいときは UnregisterAutostart.cmd で解除できます。

 これで完了です。使い方は 説明書.txt をどうぞ。


-----------------------------------------------------
 1-M. Macに入れる(所要10分)
-----------------------------------------------------

 手順1: このフォルダをMacの好きな場所に置く
   デスクトップでも書類フォルダでもどこでもOKです。

 手順2: Node.js を入れる
   https://nodejs.org/ を開き、「LTS」と書かれたボタンから
   インストーラーをダウンロードして実行します。
   設定は変えずに進めるだけで完了です。

 手順3: 起動できるようにする(ZIPで入れた場合だけ・初回のみ)
   ※「0.」の git clone で入れた場合は実行権限が付いているので、
     この手順は不要です。手順4へ進んでください。

   「ターミナル」アプリを開いて、次のように入力します。

     chmod +x

   ここまで打ったら(最後に半角スペース)、Finderで
   Start.command と backup.command を選んで
   ターミナルの窓へドラッグ&ドロップし、Enterキーを押します。

 手順4: (スマホからも使う場合)Tailscale を入れる
   Macとスマホの両方に Tailscale(無料)をインストールして
   同じアカウントでログインしてください。
   https://tailscale.com/download
   ※Macだけで使うなら不要です。

 手順5: Start.command をダブルクリック
   ターミナルの窓が開いてアプリが起動します。
   窓に表示されるアドレスをブラウザで開いてください。
   ・このMacなら ...... http://localhost:3000
   ・スマホからは ..... 窓に表示される http://100.x.x.x:3000

   ※「開発元を確認できないため開けません」「ブロックされました」と
     出たときは、初回だけ許可の操作が要ります。
     macOSのバージョンで場所が違うので注意してください。

     ・macOS 15 (Sequoia) 以降
         「システム設定」→「プライバシーとセキュリティ」を開き、
         下までスクロールすると
         「"Start.command" は…ブロックされました」と出ています。
         その右の「このまま開く」を押して許可し、
         もう一度 Start.command をダブルクリックします。

     ・macOS 14 (Sonoma) 以前
         Start.command を右クリック(またはcontrolキーを押しながら
         クリック)→「開く」を選び、確認画面でもう一度「開く」。

     ・どちらも面倒なとき(確実な方法)
         「ターミナル」で  sh  と打ち、半角スペースを1つ入れてから
         Start.command をターミナルの窓へドラッグ&ドロップして Enter。

 手順6: (おすすめ)自動起動を登録する
   「システム設定」→「一般」→「ログイン項目」を開き、
   左下の「+」から Start.command を追加します。
   やめたいときは同じ画面で「−」を押すだけです。

 ※Windows向けの「Node同梱zip」はMacでは使えません。
   手順2のNode.jsインストールが必要です。


-----------------------------------------------------
 2. 別のPCへ引っ越す(データごと移す)
-----------------------------------------------------

 手順1: 今のPCで、アプリの黒い窓を閉じる(=アプリ停止)

 手順2: このフォルダを丸ごと新PCへコピー
   USBメモリでも共有フォルダでもOK。
   記録データも設定も全部フォルダの中に入っているので、
   これだけで引っ越し完了です。

 手順3: 新PCで上の「1.」または「1-M.」の手順どおり起動
   ・Windows: Setup.bat → Start.bat
   ・Mac:     Node.jsを入れる → chmod +x → Start.command

 手順4: 旧PCで自動起動を使っていた場合
   ・旧PC: 解除(Windows: UnregisterAutostart.cmd / Mac: ログイン項目から削除)
   ・新PC: 登録(Windows: RegisterAutostart.cmd / Mac: ログイン項目に追加)

 ※スマホから使うアドレス(100.x.x.x)は新PCで変わります。
   新しいアドレスは起動時の窓で確認してください。

 ※WindowsとMacの間で移してもそのまま使えます
   (記録データの中身は共通です)。


-----------------------------------------------------
 3. アンインストール
-----------------------------------------------------

 手順1: UnregisterAutostart.cmd で自動起動を解除
        (登録していなければ不要)
 手順2: フォルダを削除するだけ
   レジストリ等は一切使っていないので、これで跡形なく消えます。
   ※記録データもフォルダの中にあるので、残したい場合は
     先に data\focus.db をどこかへコピーしてください。


-----------------------------------------------------
 4. うまくいかないとき
-----------------------------------------------------

 ■ Setup.bat で何度も [NG] になる
   Node.js のインストール後にPCを再起動してから
   もう一度試してください。

 ■ Start.bat の窓がすぐ閉じる/エラーが出る
   窓に表示されたエラーメッセージを控えて相談してください。

 ■ スマホからつながらない
   ・PC・スマホ両方が Tailscale にログインしているか確認
   ・アドレスは旧PCのものを開いていないか確認
     (引っ越し後はアドレスが変わります)

 ■ (Mac)Start.command をダブルクリックしても何も起きない
   ZIPで入れた場合は「1-M. 手順3」の chmod +x を実行したか
   確認してください(git clone で入れた場合は不要です)。

 ■ (Mac)「開発元を確認できないため開けません」と出る
   初回だけ許可の操作が要ります。macOSのバージョンで場所が違います。
   ・macOS 15以降: システム設定 →「プライバシーとセキュリティ」→
                   下の方の「このまま開く」
   ・macOS 14以前: Start.command を右クリック →「開く」
   詳しくは「1-M. 手順5」の注意書きをご覧ください。

 ■ (Mac)「Node.js が見つかりません」と出る
   ターミナルで node -v と打って反応するか確認してください。
   反応しない場合は Node.js を入れ直してください。
